internet-radio
A simple, self-hosted internet radio website.

[![GitHub license](https://img.shields.io/github/license/bigo229/internet-radio.svg)](https://github.com/bigo229/internet-radio/blob/main/LICENSE)

This project provides a basic,  website for streaming internet radio stations. It's designed for users who want a simple interface to listen to their favorite online radio without ads or complex features.

*   Plays internet radio streams.
*   Simple and clean user interface.
*   Website Containing Information On Radio Streams.
