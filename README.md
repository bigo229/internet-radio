internet-radio
A simple, self-hosted internet radio website.

[![GitHub license](https://img.shields.io/github/license/bigo229/internet-radio.svg)](https://github.com/bigo229/internet-radio/blob/main/LICENSE)

This project provides a basic, self-hosted website for streaming internet radio stations. It's designed for users who want a simple interface to listen to their favorite online radio without ads or complex features.

*   Plays internet radio streams.
*   Simple and clean user interface.
*   Easy to self-host.
*   Customizable station list.

## Installation

```bash
git clone https://github.com/bigo229/internet-radio.git
cd internet-radio
npm install
```

## Usage

1.  Edit the `stations.json` file to add your preferred internet radio streams.
2.  Run the application:

```bash
node server.js
```

3.  Open your browser to `http://localhost:3000` to access the radio player.
